Miniscore

Support

Basketball scores and player statistics for Android, iPhone and iPad.

Contact

Email s.ivica@gmail.com for help. Include your app version, device model and a description of the issue.

Find a game

Tap the menu button to browse published games. Search using a team name, team code or date, then choose a matchup.

Refresh scores

Pull down on the statistics screen to refresh. The app also checks for updates when reopened. Published data is updated daily; Miniscore is not a live play-by-play service.

Use saved games offline

After a successful refresh, the app keeps a validated copy of the game feed. If a refresh fails, the last valid games remain available. A bundled snapshot is available on first launch.

Player and game details

Tap a player for their full name and additional statistics. Tap the arrow below the score for venue and quarter scores. Substitutes are ordered by minutes and seconds played.

Privacy

Read the Miniscore privacy policy. No Miniscore account is required.
